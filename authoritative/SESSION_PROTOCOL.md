Read the next direct investigation and latest working proof. Spend the invocation on mathematics: reconstruct exact proofs, find counterexamples, seek replacement lemmas, attack the full theorem, and use computation selectively to detect structural patterns. Follow promising leads within the same research run instead of imposing a one-lemma cutoff.

Log each new proof with hypotheses and exact scope, each failed claim with a checkable witness, and every numerical observation as non-proof. Update NEXT_SESSION to tackle the hardest current gap. Commit real findings to THIS repository and use its existing GitHub tests and CI to protect the notebook. There is no parent/child architecture, no paper-stage bureaucracy, no forced fifth/tenth review and no STOP gate.

External submission, contact and announcement still require explicit human request. The conjecture is not solved unless a full independent proof is verified.
